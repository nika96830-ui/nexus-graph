# Nexus Graph

Интерактивный визуализатор силовых графов на базе **HTML/CSS/JS + D3.js v7**. Работает полностью локально в браузере без серверной части и шага сборки.

## Возможности

- Интерактивная силовая симуляция (drag-and-drop, зум, панорамирование, разогрев, заморозка, сброс позиций).
- Мгновенный поиск по имени, `id`, группе и описанию с подсветкой связанных узлов.
- Загрузка пользовательских графов в формате JSON с валидацией структуры, очисткой дубликатов и «висячих» рёбер.
- Автосохранение последнего валидного графа в `localStorage`.
- Экспорт графа в HiDPI PNG (2x) с сохранением всех стилей и подписей.
- Безопасный рендер деталей узла (защита от DOM XSS), зафиксированный D3.js v7.8.5 с SRI и строгий CSP в `vercel.json`.

## Формат JSON

```json
{
  "nodes": [
    { "id": "api", "name": "API Gateway", "group": "infra", "size": 17, "desc": "Точка входа" }
  ],
  "links": [
    { "source": "api", "target": "api", "label": "self" }
  ]
}
```

Ограничения валидатора: до 2 МБ JSON, до 1 500 узлов, до 5 000 рёбер, `size` ограничивается диапазоном `4..48`.

## Локальный запуск и проверка

```bash
# Проверка автотестов валидатора и безопасности (Node.js 18+)
npm test

# Локальный статический сервер
npx serve .
```

## Деплой на Vercel

1. Импортируйте репозиторий `nika96830-ui/nexus-graph` в [Vercel](https://vercel.com/).
2. Framework Preset: **Other** (статический сайт, Build Command не требуется, Output Directory: `.`).
3. После подключения кастомного домена обновите URL в `robots.txt` и `sitemap.xml`.
